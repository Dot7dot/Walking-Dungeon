# 步行地牢 Walking Dungeon

用**真實走路**累積步數，再用步數探索**隨機生成的地牢**。撿錢幣、開寶箱、採水果，餵地牢生物交朋友，讓牠們跟在你後面一起冒險！

👉 **開始玩：<https://dot7dot.github.io/Walking-Dungeon/>**（建議用手機開啟，可以「加入主畫面」當成 App 使用）

## 玩法

1. 在現實中每走 **50 公尺**，就得到 **1 步**。
2. 在地牢裡每移動一格消耗 1 步：點旁邊的地塊、用方向鍵（D-pad）、在地牢上滑動，或用鍵盤方向鍵／WASD。
3. 往生物或商人的方向走，是「互動」而不是移動，**不會消耗步數**。
4. 踩到出口（樓梯）前往下一層；踩到鼴鼠洞回到地底小窩。離開後，下一座地牢會重新隨機生成。
5. 新玩家會先拿到 10 步當見面禮，第一層是有一隻普通生物和一個寶箱的教學關。

## 計步方式（依序自動退回）

| 順位 | 方式 | 換算 | 說明 |
| --- | --- | --- | --- |
| ① | 📡 GPS 定位 | 50 公尺 = 1 步 | 類似 Pokémon GO 的距離計算。會過濾原地飄移與精度太差的定位，時速超過約 16 公里（搭車）不計算。 |
| ② | 📳 搖晃計步 | 搖 50 次 = 1 步 | GPS 被拒絕、不支援或收不到訊號時自動改用。手機每搖一下（或走路時每一步）記 1 次。iPhone 需要點一下授權動作感測。 |
| ③ | 🔵 藍牙跑步機／計步器 | 50 公尺 = 1 步 | 用 Web Bluetooth 連接支援 FTMS 的跑步機、步行墊，或 RSC 足部感應器，讀取實際距離（Android／電腦版 Chrome）。 |
| ③ | ✍️ 手動同步健康 App | 50 公尺 = 1 步 | 輸入「健康」、Google Fit 或手環 App 的今日總步行距離（或步數，以每步 0.7 公尺換算）。只會補上今天還沒被其他方式算到的差額，不會重複計算。 |

自動模式會先試 GPS（20 秒內沒有夠準的定位就算失敗），失敗就改用搖晃計步，再失敗就請你選擇藍牙或手動同步。也可以在「計步」面板手動指定方式。

> 網頁在螢幕關閉或切到背景時無法持續計步，走路時請保持畫面開啟（遊戲會自動要求螢幕常亮）。GPS 模式下如果螢幕關掉一陣子再回來，只要平均速度合理，期間的直線距離會補算回來。

## 地牢

- 由 1×1 的地塊組成，大小 **2×2（10%）**、**3×3（40%）**、**4×4（40%）**、**5×5（10%）**。
- 每次離開地牢（走出口或跳進鼴鼠洞）後重新隨機生成，保證所有地塊都走得到、不會被擋住。
- 三種屬性，色系各不相同：**沙土**（暖沙色）、**森林**（草綠色）、**沼澤**（青苔色）。
- 視野有限，沒探索過的地塊會被霧遮住。

## 地牢裡的資源

- **寶箱**：每種屬性的寶箱外觀與內容都不同（沙岩寶箱、樹根寶箱、苔蘚寶箱），裡面有道具、水果或零食。
- **水果**：每種屬性有 2 種普通水果與 1 種稀有水果，可以餵給地牢生物。
- **地牢生物**：餵水果增加好感度，好感度滿了就會跟在你後面（最多 3 隻），帶來能力加成；跟著你走路會累積經驗升級，在 Lv3、Lv5 取得新能力或強化能力。稀有生物只吃自己屬性的水果、需要更多好感度；傳說生物只吃特定的稀有水果。
- **鼴鼠洞**：踩上去回到地底小窩。可以佈置家具，也可以到**搖鈴區**呼喚以前收服的生物，更換隊伍成員。
- **移動商人**：浣熊商人販賣道具、水果與家具。
- **錢幣**：常常散落在地上，踩上去撿起來 +1。

## 存檔

進度自動存在瀏覽器（localStorage）。換手機或清除瀏覽資料前，可以在「設定 → 匯出存檔」複製存檔文字，之後再「匯入」還原。

## 開發

純 HTML／CSS／JavaScript（ES modules），不需要建置步驟。

```bash
npm start        # 在 http://localhost:8080 啟動本機伺服器（python3 -m http.server）
npm test         # 執行單元測試（Node 22 內建 node:test）
```

- 網址加上 `?dev` 會在「計步」面板出現開發者工具（模擬走路、加步數、加錢幣、換樓層）。
- 定位與動作感測只能在 HTTPS 或 `localhost` 下使用。

| 檔案 | 內容 |
| --- | --- |
| `js/data.js` | 屬性、水果、道具、家具、生物、能力等遊戲資料 |
| `js/logic.js` | 遊戲規則：地牢生成、移動、餵食、商店、道具、小窩（不碰 DOM，可在 Node 測試） |
| `js/tracker.js` | 計步：GPS 距離累積、搖晃偵測、藍牙 FTMS／RSC 解析、自動退回流程 |
| `js/main.js` | 畫面、操作與各種面板 |
| `js/sprites.js` | 手繪 SVG（玩家、寶箱、鼴鼠洞、樓梯…） |
| `sw.js` | 離線快取（訊號不好時也能開啟） |

## 發佈

推送到 `main` 後，GitHub Actions（`.github/workflows/pages.yml`）會先跑測試，再把遊戲檔案推到 `gh-pages` 分支，由 GitHub Pages 發佈。

如果網站沒有出現，請到 repository 的 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 **`gh-pages`**、資料夾選 **`/ (root)`** 後儲存，等一兩分鐘即可。
